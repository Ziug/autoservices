# Новая студия за несколько минут

1. Создайте профиль: `pnpm tenant:new north-studio`.
2. Отредактируйте единственный файл `tenants/north-studio/business.json`: название, описание, город, адрес, телефон, карту, часовой пояс, расписание, услуги, длительность и цены, боксы, три карточки и вопросы помощнику. Пока `demo: true` и `status: "preview"`, это безопасный образец.
3. Положите фотографию главного экрана в `tenants/north-studio/images/hero.jpg`, логотип — в `tenants/north-studio/images/mark.svg`; замените образцы фотографий в галерее. Файлы публикуются как `/tenants/north-studio/images/...`.
4. Проверьте профиль: `pnpm tenant:validate north-studio`. Для предпросмотра выполните `pnpm dev` и откройте `/s/north-studio/`.
5. Для реальной студии подключите Supabase по [инструкции развёртывания](DEPLOYMENT.md), задайте серверные секреты и создайте доступ владельца в панели администратора (карточка студии → «Владельцы»: логин и пароль, почта необязательна). В JSON выставьте `demo: false` и `status: "live"` после проверки настроек.
6. Выполните `pnpm tenant:publish north-studio`, соберите и опубликуйте сайт в Vercel или Cloudflare Pages, задайте `PUBLIC_BASE_URL`, затем выполните `pnpm tenant:verify north-studio` и `pnpm tenant:activate north-studio`.

Новый профиль, услуги и боксы синхронизируются, пока студия остаётся в `preview`. Команда активации требует `demo: false`, настроенный публичный URL и проверенные записи Supabase. Демонстрационный профиль нельзя опубликовать как live. Повторная публикация live-студии сохраняет записи и фотографии, загруженные владельцем. Новые студии не требуют изменения исходного кода.
