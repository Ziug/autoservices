Сделай готовое приложение для записи в автосервис или детейлинг-студию. Оно должно работать по обычной ссылке на телефоне и компьютере. Клиенту не нужно регистрироваться или что-либо устанавливать. При желании он сможет добавить приложение на главный экран телефона, после чего оно будет открываться без адресной строки, со своей иконкой.Это приложение нужно для эксперимента: за сутки я собираю варианты для 10–15 реальных студий и отправляю каждому владельцу готовую ссылку. Поэтому новое название, цены, адрес, телефон, график и фотографии должны подставляться за несколько минут. Не разбрасывай эти данные по коду. Храни настройки каждой студии в одном файле и дай владельцу возможность менять основные данные в своём кабинете.Используй следующий набор технологий:- TypeScript, React, Vite и React Router для приложения.- Astryx Design System и Phosphor Icons для интерфейса.- TanStack Query для получения и обновления данных.- Zod для проверки данных, которые вводят люди.- Supabase для базы данных, входа владельца, хранения фотографий и серверных функций.- date-fns и date-fns-tz для дат и часового пояса студии.- OpenAI SDK для помощника с возможностью менять модель через настройки сервера.- vite-plugin-pwa и Workbox для установки приложения и работы без сети там, где это возможно.- liquid-gl для настоящего стеклянного эффекта.- Vitest и Playwright для проверок.- Vercel для публикации сайта. Используй pnpm.Как должно выглядеть приложениеСделай тёмный, аккуратный интерфейс: чёрный фон, белый текст и яркий синий цвет #4690FF. Текст должен хорошо читаться на телефоне. На главной странице размести большое фото машины, название студии, краткое описание, услуги с ценами, фотографии работ, адрес, время работы и понятные кнопки записи.Над карточкой записи поставь заметный заголовок «Запись в студию». Внизу телефона сделай навигацию «Главная», «Услуги», «Моя запись» со стеклянным эффектом. Она не должна закрывать содержимое страницы. Добавь плавное появление разделов при прокрутке. Если человек отключил анимации в настройках устройства, уважай этот выбор.На главном фото нужна широкая кнопка «Записаться» с таким же настоящим стеклянным эффектом, как у нижней панели. Кнопка должна двигаться вместе с фотографией. При прокрутке внутри неё не должны появляться буквы из соседних разделов, а надпись на самой кнопке должна оставаться чёткой.Что может клиентКлиент смотрит услуги, цены и примеры работ. Для записи он выбирает услугу, дату и свободное время, затем вводит имя, телефон и автомобиль и подтверждает запись. Занятое время должно быть явно отмечено. После подтверждения он видит подробности своей записи и при необходимости может её отменить по правилам студии.Свободное время рассчитывай по настоящему графику работы, занятости боксов, длительности услуги и времени на подготовку между машинами. Если машина занимает бокс два дня, эти два дня должны быть заняты.Добавь помощника, которому можно написать обычным языком: «Когда ближайшее окно?», «Сколько стоит полировка?», «Как найти студию?». Сразу покажи эти примеры как кнопки, чтобы человек мог начать разговор одним нажатием. Помощник должен отвечать по услугам и свободному времени именно этой студии. Если данных не хватает, пусть задаёт уточняющий вопрос.После записи предложи включить напоминание за сутки. Там, где уведомления недоступны, дай возможность добавить запись в календарь.Что может владелецСделай отдельный кабинет с входом по почте и паролю. Владелец видит записи на день и неделю, количество заездов, завершённых работ и реально полученные деньги. Он может добавить запись вручную, перенести или отменить её, отметить машину как принятую или готовую, внести оплату либо возврат.В кабинете владелец меняет услуги, цены, длительность работ, боксы, часы работы, выходные, адрес, телефон, логотип и главное фото. Он также меняет три информационные карточки на главной странице.Для фотографий работ сделай три понятных действия: добавить новую карточку, заменить конкретную фотографию, изменить подпись под конкретной фотографией. Если владелец загрузил одно фото, остальные работы должны остаться на месте.Помощник владельца должен понимать вопросы вроде «Что у меня завтра?», «Сколько машин было на неделе?» и «Сколько денег получено?». Ответы бери из базы записей и оплат этой студии.НадёжностьУ каждой студии должны быть свои данные. Владелец одной студии не должен видеть записи другой. Проверяй права доступа на сервере. Не передавай ключи базы и модели в код сайта.Создавай запись в базе как одну неделимую операцию. Если два человека одновременно выбрали один бокс и время, успешной должна стать только одна запись. Повторное нажатие кнопки подтверждения не должно создавать копию записи.Помощник сначала получает нужные сведения через серверные функции и только потом отвечает. Он не должен придумывать записи или свободное время. Клиентскому помощнику нельзя открывать список всех клиентов, а помощнику владельца нельзя менять данные по собственной инициативе. Поставь предел на частоту обращений и расходы на модель.Быстрая настройка новой студииСделай папку tenants/<название>/ с одним файлом настроек и фотографиями. Добавь команды для создания новой студии, проверки её настроек, публикации и проверки готовой ссылки. До проверки новая студия должна быть доступна только как образец. Для каждой студии создай собственный адрес вида /s/<название>/, иконку и настройки установки на телефон.Инструменты агентаЕсли доступны MCP для Supabase и Vercel, используй их при работе с базой и публикации. Если их нет, используй официальные программы командной строки. Для проверки сайта на телефоне и компьютере используй браузерный MCP или Playwright.Примени skill ui-ux-pro-max при проектировании и проверке интерфейса. Перед созданием страниц изучи Astryx через его команды build, template, component, docs layout и docs tokens. Если доступен skill imagegen, можешь сделать временные изображения для образца, но фотографии, предоставленные владельцем, всегда важнее.MCP нужны агенту, который создаёт приложение. Помощник внутри готового приложения должен получать сведения через наши серверные функции с проверкой прав.Заверши работу только тогда, когда клиент может сделать запись, владелец видит её в кабинете, занятое время нельзя забронировать повторно, помощник отвечает по настоящим данным, приложение устанавливается на телефон, а новую студию можно подготовить без изменения исходного кода.Проверь основные действия на телефоне и компьютере. После публикации дай мне рабочую ссылку, короткую инструкцию по настройке новой студии и список того, что ты действительно проверил.
